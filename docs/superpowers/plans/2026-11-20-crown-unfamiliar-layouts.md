# Unfamiliar-plan review trial

> **For agentic workers:** Execute the approved fresh synthetic-review round, preserve the frozen answers and findings, and use observed misses to choose a bounded fix. Do not ask the user for work files.

**Goal:** Measure ordinary drafting review on layouts outside the existing benchmark and protect improvements with regression tests.

**Architecture:** An independent fixture author creates four paired layout families. Six initial cases are reviewed before the answer key is opened. Two reserved cases remain unseen until the initial findings and any resulting changes are frozen. Each reviewer receives only one invented PDF, its job brief and neutral review instructions. Grade saved source-bound observations against frozen developer-authored truth.

**Baseline:** Crown Plan Agent 0.7.8 at `653a67e`; maintained dependency locks and ordinary review tools remain unchanged.

## Constraints

- No work documents, current regulator downloads, new dependencies, custom native builds or vulnerability tests.
- Generate fresh LOC/MSL-style layouts and literals, not mutations of the existing drawing factory.
- Include clean controls, legitimate inset/history/different-area contexts and visually readable raster/rotated text.
- Give every planted defect an explicit invented job expectation; do not plant unsupported legal, ownership, control or field-geometry conclusions.
- Freeze and hash the oracle before review. Never change it to match the model's answers.
- Keep generator source, truth, other cases and prior results out of reviewer inputs. Record these as procedural controls, not filesystem isolation.
- Save findings before grading. Count misses, false alarms, duplicate findings and false clearances explicitly; retain ambiguity and unsupported claims.
- Keep deterministic benchmark results, assisted model-trial results and professional acceptance separate.
- Reused cases become regression cases after publication; they are no longer fresh holdouts.
- All original/generated PDFs and detailed trial outputs remain outside the repository and package.
