# Smoother source-bound plan review

The user authorized improving whole-plan intake, text-area selection, common
number formats and visual routing, then testing known cases and fresh layouts.
The user also described opposite text facings near north; approximately 350
degrees is unconfirmed and must not become a drafting-rule violation threshold.

## Chosen approach

Add an offline source-bound intake map and a check-preparation helper around the
existing checker. Automatically derive complete native-text support rectangles
inside explicitly reviewed semantic contexts. Preserve the geometric evaluator's
clipping, raster, ambiguity, independence and completeness gates. This avoids
arbitrary span allowlists that could conceal competing totals. Expanding boxes
without context was rejected because it can substitute history or inset text.
Adding OCR or a remote recognition dependency is outside this change.

The map records actual source digest, sheet geometry/rotation, native text
directions and locators, image rectangles, unsupported or incomplete native
evidence, candidate labels/headings and explicit visual tasks. Discovered roles
are candidates, not verified titleblock/main-view identities or requirements.
The assistant still reads complete titleblocks/Notes and verifies each context.

Check preparation selects observed literal labels within supplied contexts and
uses bounded overlap closure to fully include intersecting native font boxes.
Every competing same-label match stays visible; no first/nearest or expected-
value matching. If closure leaves the context, encounters unsafe evidence, or
cannot isolate the requested condition, leave a source-located followup. Never
invent completeness declarations. Ready checks produce a normal v1 finished-
plan spec; unresolved requests remain explicit in the preparation result.

Support plain decimal amounts and consistently grouped thousands (comma or
space, including normalized nonbreaking space), with at most one terminal
sentence period after the canonical unit. Preserve exact Decimal arithmetic,
canonical tolerances/units and all multiple/blank/competing-value gates. Add an
explicit m^2 alias for m2 alongside existing m² normalization. Reject malformed
grouping, mixed separators, signs, exponents, decimal commas and extra content.
Scale parsing consumes the entire denominator candidate, including malformed
continuations, rather than accepting a numeric prefix. One terminal period is
allowed; malformed or multiple ratios stay unresolved.

## Acceptance

- Reproduce saved clipping/format failures first; never mutate historical data.
- Test source binding, context boundaries, competing current/history labels,
  adjacent parcels and insets, raster/clipped/outlined evidence, native oblique
  and opposite directions, duplicates, invalid inputs and protected outputs.
- Read each label in its own native direction; azimuth, PDF axes and readability
  flips remain distinct. Test mixed orientations around north without imposing
  the unconfirmed office cutoff.
- Exercise known regression packets and newly invented layouts. Preserve new
  inputs, frozen expectations, actual tool outputs and dated results separately
  from the historical 12/12 assisted record.
- Keep existing dependency/runtime/source/privacy gates; add no dependency and
  make no current-law, control, regulatory or professional acceptance claim.

Implementation choices above are the assistant's technical decisions within the
authorized scope, not additional drafting conventions confirmed by the user.
