# Counsel review protocol
Freeze a neutral brief containing objective, options, constraints, verified facts with source identifiers, assumptions and unknowns. Each of five genuinely isolated workers receives the same brief and only its assigned perspective. Do not pass earlier worker conclusions to later first-pass workers.
Collect each position, strongest evidence, material uncertainty and next action. For cross-review, remove explicit author metadata, label the cases, and give each worker the other four cases with the shared brief. Labels are not guaranteed anonymity. Allow corrections; circulate newly verified facts equally. If worker isolation or review is unavailable, describe the process as a single-assistant analysis.
The coordinator synthesizes supported agreement and disagreements, decisive evidence, recommendation, reversal condition, confidence rationale, measurable next step and authorization boundary. Never count votes as proof or represent advice as implementation testing.
