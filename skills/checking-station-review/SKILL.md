# Checking Station Review

Identify artifact version, input evidence, acceptance criteria and intended use. Perform deterministic checks first: file integrity, schema, required layers and fields, coordinate system, geometry validity, topology, closure, widths, areas, counts, tolerances and round-trip readback as applicable. Separate hard failures from warnings and missing evidence. Use AI only to interpret results, propose diagnoses and prepare reproducible defect reports. Do not convert warnings into PASS without explicit approved criteria. Return PASS, FAIL, REVIEW_REQUIRED or BLOCKED with measured evidence and reviewer identity. An artifact opening successfully is not proof of technical correctness.
