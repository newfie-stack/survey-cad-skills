# Skill Evaluation & Regression Testing

Freeze the skill version, test environment, tools and expected behavior. Build synthetic positive, negative, ambiguous and adversarial test cases with objective expected outcomes. Separate failures caused by the skill's instructions from model limitations, extraction errors, missing tools, runtime faults and end-to-end application defects. Run baseline and skill-enabled tests under comparable conditions. Record prompts, input hashes, expected and observed results, tool availability and reproducibility. Report PASS, FAIL, REVIEW_REQUIRED or BLOCKED with evidence. Never claim a test ran unless logs or artifacts substantiate it. Preserve failed cases as regression fixtures; do not promote an untested example to proof of general reliability.
