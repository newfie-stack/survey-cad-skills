# CAD/GIS Object Inspection

Read available CAD/GIS entities, layer names, geometry types, extents, CRS, units, object attributes and source identifiers. Preserve each source feature's stable ID and raw evidence. Classify geometry and attribute roles as observations with explicit uncertainty; distinguish source facts from inferred interpretation. Route exact coordinate transformations, topology, intersections and file writing to deterministic validated libraries. Never assume layer names alone prove legal boundary identity. Do not mutate input files during inspection. Produce an evidence register containing entity ID, geometry type, source layer, attributes, CRS, classification, confidence and unresolved questions.
