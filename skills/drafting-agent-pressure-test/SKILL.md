# Drafting Agent Pressure Test

Evaluate a drafting agent with synthetic cases involving local versus georeferenced coordinates, units, CRS, bearing basis, legal versus contextual boundaries, road allowances, missing control, conflicting observations, legacy CAD compatibility and plausible-looking but incorrect geometry. Require source evidence, deterministic computation and uncertainty handling. Score endpoint identity, geometry invariants, validation results and refusal to invent missing survey data separately from presentation quality. Include adversarial cases that reward REVIEW_REQUIRED instead of guesses. Record inputs, expected outcomes, observed outputs and reproducible defects. Do not use client drawings or proprietary drafting standards as public fixtures.
