# Development preview publication scope

The owner authorized adding Crown Plan Agent 0.3.1 to the existing public
[newfie-stack/survey-cad-skills repository](https://github.com/newfie-stack/survey-cad-skills).
This is a development preview for assisted reviews. Production readiness,
regulatory acceptance and completion of the master checklist are not established
by publication.

## Included material

The publication copies reviewed, independently authored skill instructions,
Python source, structured review catalogues, invented tests and documentation.
Authorized case summaries use fictional company names. Original real plans,
source PDFs, images, extracted inventories, coordinates, CAD drawings, full case
reports, identifying mappings and credentials remain outside the public files.
Private development history is not imported into this repository.

Historical test counts, source fingerprints and private integration IDs in the
review records identify earlier evidence. They are not substitutes for the
public addition's own commit, checks or installation verification. Original
source publications are cited; no complete regulator publication is bundled.

## License and dependencies

The repository's existing
[MIT license](https://github.com/newfie-stack/survey-cad-skills/blob/main/LICENSE)
covers its original contributions. It does not relicense regulator publications,
external software or other third-party material.

PDF inspection uses the separately installed PyMuPDF dependency, whose publisher
offers [AGPL and commercial licensing options](https://pymupdf.readthedocs.io/en/latest/about.html#license-and-copyright).
Users and distributors must establish the appropriate licensing basis for their
installation and distribution model. The preview contains no PyMuPDF binaries.

Reconstruction requires separately authorized access to a reviewed Octopus
checkout, following the [provider contract](references/octopus-reconstruction.md).
Octopus source, dependencies, access rights and licensing are not included in
this publication. Its absence leaves reconstruction blocked; the offline PDF
review and invented example remain available.

## Verification boundary

Verify the public addition's exact commit, changed files, secret/privacy scan,
relative links, metadata, synthetic smoke and CI results. Keep project evidence
and private test inputs outside the repository. Native skill discovery in a
fresh host session remains unverified, and the documented manual loading route
must not be described as automatic discovery acceptance.

The [release notes](RELEASE_NOTES.md), [technical review](TECHNICAL_REVIEW.md) and
[master checklist](MASTER_CHECKLIST.md) retain the supported behavior and open
source, geometry and professional-review gates.
