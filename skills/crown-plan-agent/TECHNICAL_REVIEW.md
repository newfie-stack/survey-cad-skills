The following are coverage or acceptance limits, not newly discovered implementation defects:

- The 14-entry candidate catalogue is a partial review checklist. Clause accuracy, exceptions, supersession, jurisdiction, current source authority and complete regulatory coverage were not independently established.
- The Table A2 parser supports one pinned revision/layout. Its two supplied-PDF integration tests now pass for the authorized October 2026 source in the coordinating agent's latest run. This supports that revision's tested extraction/lookup path; it does not establish supersession, current normative authority or compatibility with later layouts. Table A1 remains a manual review.
- Scanned/outlined text, symbols, rectangles, hatches and semantic drawing roles are not fully interpreted. Whole-span matching and proximity/orientation/leader heuristics can miss or misidentify candidates. Extraction caps do not establish hostile-file sandboxing; span-by-vector ranking also has potentially large pairwise work.
- Survey geometry supports supplied straight-edged single rings and ordered traverses, not complete cadastral reconstruction, holes, multipart boundaries, surveyed curves, dimension chains, ties or plan/CAD/GIS consistency. CRS verification and boundary/annotation identity depend on independently checked caller evidence. Decimal arithmetic preserves supplied decimal values; it does not establish coordinate accuracy.
- Filenames and page/bbox locations provide traceability within the supplied review package, not immutable input identity. The CLI writes Markdown; the structured ledger is a Python result rather than an exported JSON CLI artifact. Source verification timestamps and other unavailable contract values remain unresolved.
- The coordinating agent reports one authorized private case was independently baselined and processed by the engine outside the repository. These reviewers did not assess that case or its evidence. One case does not establish general real-world acceptance, and qualified survey/regulatory sign-off remains open. Clean-install acceptance, remote CI execution and production-release acceptance were not performed by these reviewers.
