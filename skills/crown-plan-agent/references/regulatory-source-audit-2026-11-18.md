## What the record means

Each inventory `record_check` distinguishes official HTML, indexed metadata,
supplied dated content, blocked records and the remaining unverified questions.
Keep the supplied edition and clause inspection dates. A refreshed listing
observation does not refresh an uninspected PDF's clause verification date.

Blocked publication records are marked unresolved. They were not bypassed with
mirrors or treated as evidence that no newer document exists. Search-result
publish/crawl labels are not publication or effective dates. Canonical CDN
equivalence is not assumed from indexed URL discovery.

Primary HTML and existing supplied PDFs were the evidence basis. No new PDF
files were saved to the workspace. Two legislation-index links unexpectedly
resolved to web PDF views; their contents were excluded from the conclusions.
Private source identities, file hashes, project inputs and full reference PDFs
remain outside this repository and plugin package.

This maintenance record does not add live downloading, automatic current-source
attestation or normative PASS/FAIL decisions. Exact applicable clauses and plan
evidence must still pass the skill's independent source/evidence gates.
