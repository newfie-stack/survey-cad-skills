# Reconstruction acceptance checklist
- [ ] Source identity and page references retained
- [ ] Every subject edge has a supported observation or documented deterministic derivation
- [ ] Subject boundary, control, traverse and contextual evidence are distinct
- [ ] Endpoint identities and side membership verified
- [ ] Printed bearings, distances, curves and widths checked numerically
- [ ] Road allowance and terminal geometry independently established
- [ ] Closed boundaries checked for gaps, overlap and self-intersection
- [ ] Area, independent ties and source overlay checked with recorded residuals
- [ ] CRS, units, ground/grid status and alignment provenance recorded
- [ ] Unresolved ambiguity labeled REVIEW_REQUIRED
- [ ] CAD artifact reopened and inspected
PASS requires all applicable mandatory checks; a visual match alone never qualifies.

## Full evidence network gate
- [ ] Every printed bearing-and-distance course inventoried with source locator and role
- [ ] Section/quarter, road, existing-boundary and tie/control courses represented separately from subject geometry
- [ ] Found monuments and assumed/calculated endpoints distinguished
- [ ] Each inventoried course linked to a CAD entity or explicit unresolved/omitted reason
- [ ] Full review preview shows evidence network; boundary-only export labeled derivative
- [ ] Source-course completeness counts reported; no omitted course for PASS
See [dimensioned evidence completeness](dimensioned-evidence-completeness.md).

## Conditional gates
- [ ] Multi-section: every required cut is evidence-linked; each printed parcel/quarter area checked in its own scope; no gaps, overlaps or hidden road area.
- [ ] Multiple plans/alignment: accepted local solution retained; fit and independent check anchors distinguished; absolute placement status separate.
- [ ] Posted terminal or reference setback: exact accepted pin or source-proven ordered derivation; no snapping of conflicting evidence.
- [ ] CAD freshness: reopened file and report bound to current source, reviewed decisions and generation; failed or stale candidate cannot replace accepted output.
