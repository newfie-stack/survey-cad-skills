# Field-note evidence rules
- Keep original point IDs, Northing/Easting order, coordinate reference system, units and descriptions intact.
- Distinguish found, placed, calculated and approximate or reported evidence.
- A feature drawn on a sketch may be reference context and may have no new point shot.
- A travelled trail or utility sketch is not automatically a legal access or utility boundary.
- Treat notes and enlarged details as source evidence; link each to the correct feature.
- Record conflicting or off-page evidence as unresolved rather than extrapolating.
- Require source-backed start/end point identity, feature identity and edge role before creating surveyed boundary segments.
- Never include actual private field-book examples in public skill fixtures.
