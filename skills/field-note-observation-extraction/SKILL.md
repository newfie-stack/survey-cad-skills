# Field Note Observation Extraction
Extract point identifiers, descriptions, bearings, distances, offsets, evidence states, feature labels and contextual topography. Surveyed point coordinates remain authoritative for their own observations; sketch linework alone is not proof of surveyed connectivity. Separate proposed/new survey, existing registered boundaries, ties, traverses, utility reports and physical features. Resolve point-to-feature and side membership before drafting. Read [field-note evidence rules](references/field-note-evidence-rules.md).
